# Contributing to 慢慢赚钱

Thanks for helping 慢慢赚钱 stay small, private and pleasant to use.

- Keep the runtime dependency-free unless a change has a clear user benefit.
- Do not add analytics, tracking pixels, remote font loading, or account requirements.
- Do not commit personal configuration, screenshots containing real salary figures, usernames, email addresses, tokens, or local paths.
- Run `python -m unittest discover -s tests -v` before opening a pull request.

Please describe the user-facing change and include tests for schedule-calculation changes.
